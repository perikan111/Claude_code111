# TRPGルールブック

## 基本ルール

### キャラクター作成

プレイヤーは以下の要素を持つキャラクターを作成します：

#### 能力値（1〜20）

- **筋力（STR）**: 物理攻撃力、持久力
- **敏捷（DEX）**: 回避、先制攻撃
- **知力（INT）**: 魔法力、知識判定
- **体力（CON）**: HP、病気への耐性
- **精神（WIS）**: 洞察力、精神攻撃への耐性
- **魅力（CHA）**: 交渉、リーダーシップ

#### HP（ヒットポイント）

- 計算式: `(体力 × 5) + クラスボーナス`
- 0になると気絶、-10で死亡

#### MP（マジックポイント）

- 計算式: `(知力 × 3) + クラスボーナス`
- 魔法使用に必要

### クラス（職業）

#### 戦士（Fighter）

- **特徴**: 高HP、優れた武器使用
- **HPボーナス**: +20
- **MPボーナス**: +5
- **得意能力**: 筋力、体力
- **装備**: 重装備可能

#### 魔法使い（Mage）

- **特徴**: 強力な魔法
- **HPボーナス**: +5
- **MPボーナス**: +30
- **得意能力**: 知力、精神
- **装備**: 軽装備のみ

#### 盗賊（Rogue）

- **特徴**: 隠密、罠解除
- **HPボーナス**: +10
- **MPボーナス**: +10
- **得意能力**: 敏捷、魅力
- **特殊技能**: 鍵開け、隠密行動

#### 僧侶（Priest）

- **特徴**: 治癒魔法、防御
- **HPボーナス**: +15
- **MPボーナス**: +20
- **得意能力**: 精神、体力
- **特殊能力**: 治癒魔法、アンデッド退散

## 判定ルール

### 基本判定（d20システム）

行動の成否は20面ダイス（d20）で判定します。

```
判定値 = d20 + 能力値 + スキル修正
```

- **目標値10以下**: 簡単な行動
- **目標値15**: 普通の難易度
- **目標値20**: 困難な行動
- **目標値25以上**: 極めて困難

### クリティカル

- **20（自然）**: 自動成功 + 追加効果
- **1（自然）**: 自動失敗 + 悪影響

### 有利/不利

- **有利**: 2d20の高い方を採用
- **不利**: 2d20の低い方を採用

## 戦闘ルール

### イニシアチブ

戦闘開始時に行動順を決定：

```
イニシアチブ = d20 + 敏捷ボーナス
```

### 行動

1ターンに以下が可能：

- **移動**: 30フィート（約9m）
- **アクション**: 攻撃、魔法、アイテム使用など
- **ボーナスアクション**: 簡単な行動

### 攻撃判定

```
攻撃判定 = d20 + 能力修正 + 武器ボーナス
```

相手のAC（防御力）以上で命中。

### ダメージ計算

```
ダメージ = 武器ダイス + 能力修正
```

例：
- ロングソード: 1d8 + 筋力修正
- ファイアボール: 8d6

### 防御力（AC）

```
AC = 10 + 敏捷修正 + 防具ボーナス
```

### 状態異常

- **毒**: 1ターンごとに1d6ダメージ
- **麻痺**: 行動不能
- **混乱**: ランダムな対象を攻撃
- **気絶**: AC-5、自動クリティカルヒット

## 魔法ルール

### 魔法の使用

1. MPを消費
2. 詠唱判定（INT or WIS + d20 vs 魔法難易度）
3. 成功で効果発動

### 魔法レベル

- **レベル1**: 消費MP 5
- **レベル2**: 消費MP 10
- **レベル3**: 消費MP 20
- **レベル4**: 消費MP 40
- **レベル5**: 消費MP 80

### 代表的な魔法

#### 攻撃魔法

- **ファイアボール（レベル3）**: 8d6ダメージ、範囲攻撃
- **ライトニングボルト（レベル3）**: 8d6ダメージ、直線
- **マジックミサイル（レベル1）**: 自動命中、3d4+3ダメージ

#### 治癒魔法

- **キュアウーンズ（レベル1）**: 1d8+修正値 HP回復
- **ヒール（レベル3）**: 70HP回復
- **リザレクション（レベル5）**: 死者を蘇生

#### 補助魔法

- **シールド（レベル1）**: AC+5（1ターン）
- **ヘイスト（レベル3）**: 行動回数2倍
- **インビジビリティ（レベル2）**: 透明化

## スキル判定

### 技能一覧

- **運動**: 登る、泳ぐ、跳ぶ
- **隠密**: こっそり移動
- **知覚**: 罠や隠された物の発見
- **説得**: 交渉、説得
- **威圧**: 脅迫
- **医療**: 応急手当
- **魔法学**: 魔法の知識
- **歴史**: 過去の出来事の知識

### 判定方法

```
スキル判定 = d20 + 関連能力修正 + 習熟ボーナス
```

## 経験値とレベルアップ

### 経験値獲得

- 戦闘勝利
- クエスト達成
- 問題解決
- ロールプレイ

### レベルアップ

- **レベル2**: 300XP
- **レベル3**: 900XP
- **レベル4**: 2700XP
- **レベル5**: 6500XP

レベルアップ時：

1. HP増加（クラスダイス + 体力修正）
2. 新しい能力習得
3. 能力値上昇（レベル4,8,12...）

## 休息ルール

### 短休息（1時間）

- HP回復: クラスダイス分
- 一部のスキル回復

### 長休息（8時間）

- HP/MP完全回復
- すべてのスキル回復
- 状態異常治癒

## アイテムと装備

### 武器

- **ダガー**: 1d4ダメージ、投擲可能
- **ロングソード**: 1d8ダメージ
- **グレートソード**: 2d6ダメージ、両手
- **ロングボウ**: 1d8ダメージ、射程150ft

### 防具

- **レザーアーマー**: AC+1
- **チェインメイル**: AC+6
- **プレートアーマー**: AC+8、敏捷ペナルティ

### 魔法のアイテム

希少で高価。特殊な効果を持つ。

## GMガイドライン

### セッション進行

1. シーン設定の描写
2. プレイヤーの行動受付
3. 判定・結果の処理
4. 次のシーンへ

### 難易度調整

プレイヤーのレベルと人数に応じて敵の強さを調整。

### 報酬の目安

- レベル1: 50〜100ゴールド/クエスト
- レベル3: 200〜500ゴールド/クエスト
- レベル5: 1000〜3000ゴールド/クエスト
